# Future of Knowledge — Amsterdam 2026

Site for a two-day convening at the University of Amsterdam,
16–17 November 2026.

Built with Jekyll on the [minimal](https://github.com/pages-themes/minimal)
theme, served by GitHub Pages from the `main` branch.

## Local preview

    bundle install
    bundle exec jekyll serve

Then open http://localhost:4000

## Editing

- `index.md` — overview
- `programme.md` — schedule
- `public-session.md` — the open afternoon
- `practical.md` — venue, travel, expenses
- `_config.yml` — title, dates, sidebar navigation
- `assets/css/style.scss` — styling overrides
